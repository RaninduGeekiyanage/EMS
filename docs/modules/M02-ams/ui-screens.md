# M02 UI Screens & Navigation

1. **Shift Configuration**: List and modal editor for shift definitions and grace limits.
2. **Work Calendar**: Interactive annual holiday and weekend scheduler.
3. **Attendance File Import**: Drag-and-drop file upload, format selector, and live preview data grid.
4. **Daily Attendance Ledger**: Date filter, employee search, manual punch adjustment modal with audit reason.
5. **Leave Portal**: Employee submission screen, manager approval dashboard, and annual entitlement balance matrix.
