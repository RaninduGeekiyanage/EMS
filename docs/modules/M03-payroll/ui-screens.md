# M03 UI Screens

1. **Payroll Run Dashboard**: Period selection, run status, validation alerts.
2. **Preview & Adjustments**: Interactive data grid allowing ad-hoc allowance/deduction additions before locking.
3. **Payslip Generator & Portal**: Bulk download ZIP or individual PDF viewer.
4. **Statutory Schedule Exports**: EPF R2 and ETF export buttons.
5. **Bank Disbursal Export**: Bank selector (BoC, ComBank, Sampath, HNB, People's, NSB) and download link.
