# Payroll Calculation Engine Formulas

## 1. Hourly Rate Determination
`Hourly Rate = Basic Salary / (200 hours)` or explicit contract rate.

## 2. Net Pay Formula
`Net Pay = (Gross Earnings) - (EPF 8% + APIT Tax + Salary Advances + Loan Deductions + No-Pay Deductions)`

## 3. Statutory Base
`EPF Eligible Earnings = Basic Salary + Cost of Living Allowance (COLA)`
