# Sri Lanka Bank File Formats

## Supported Bank Formats
1. **Bank of Ceylon (BoC)**: CEFTS / SLIPS formatted fixed-width file.
2. **Commercial Bank**: ComBank standard bulk direct credit CSV layout.
3. **Sampath Bank**: Sampath Direct Credit text layout.
4. **Hatton National Bank (HNB)**: HNB PayGate CSV format.
5. **People's Bank**: People's Corporate Banking transfer template.
6. **National Savings Bank (NSB)**: NSB corporate bulk salary file format.
