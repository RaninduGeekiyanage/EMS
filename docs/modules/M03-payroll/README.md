# M03: Payroll & Statutory Compliance

## 1. Overview
M03 automates compensation calculations for Monthly Salaried, Daily Rate, and Hourly Rate personnel based on attendance metrics compiled in M02. It incorporates statutory deductions (EPF 8%, ETF 3%, APIT Tax) when enabled, applies loan and advance deductions, generates official PDF payslips, and outputs bank transfer files for Sri Lankan commercial banks.

## 2. Dependencies
Requires **M01 (Master)** and **M02 (AMS)** complete and signed off.
