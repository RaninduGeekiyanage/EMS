# M01: Organization & Employee Master

## 1. Overview
Foundational module establishing multi-tenant company configurations, branch locations, hierarchy departments, job titles/designations, employee records, payment configurations, and role-based permissions.

## 2. Core Entities
- Tenants & Tenant Settings
- Companies & Branches
- Departments & Designations
- Wages Board Categories
- Employees & Identity Documents
- Payment Info (Monthly / Daily / Hourly)
- Bank & EPF/ETF Profiles
