# Antigravity Agent Session Guide

## Session Initialization
1. Agent reads `AGENT.md` at root.
2. Agent reads `docs/rules/AGENT_RULES.md`.
3. Agent checks `docs/tasks/MASTER_TASK_LIST.md` to confirm the active module.
4. Agent opens active module's `TASKS.md`, identifies next `[ ]`, marks `[/]`, and implements.
